# MarketMate

Market online store application.

The web app lives in [`market-mate`](market-mate/).

## Checks

- `just lint` runs pre-commit and the market-mate linters
- `just test` runs lint and the TypeScript check
- Pull requests to `develop`, `staging`, and `main` run the same checks in GitHub Actions

See [CONTRIBUTING.md](CONTRIBUTING.md) and [.github/workflows/README.md](.github/workflows/README.md).
